============================================================
  CARA MEMULAI SISTEM
============================================================

PRASYARAT:
1. Pastikan Docker Desktop sudah terinstall dan sedang berjalan
2. Pastikan file .env ada di root folder (sejajar docker-compose.yml)
   Isi file .env:

     # Wajib:
     GOOGLE_API_KEY=isi_api_key_kamu_di_sini
     CHROMA_SERVER_HOST=chromadb
     CHROMA_SERVER_HTTP_PORT=8000

     # Konfigurasi LLM (opsional, default: Gemini 2.5 Flash):
     LLM_PROVIDER=gemini          # pilihan: gemini | openai | anthropic | deepseek
     LLM_MODEL=gemini-2.5-flash   # sesuaikan dengan provider

     # API Key provider lain (isi hanya jika ganti provider):
     # OPENAI_API_KEY=
     # ANTHROPIC_API_KEY=
     # DEEPSEEK_API_KEY=

3. Pastikan file .env ada di folder frontend-jalan
    Isi file .env:
     VITE_API_URL=http://localhost:8080

LANGKAH MEMULAI:
1. Buka terminal (PowerShell atau Command Prompt atau terminal VS Code)
2. Masuk ke folder project
3. Jalankan semua service:
     docker-compose up -d
4. Tunggu sekitar 30-60 detik sampai semua container siap
5. Buka aplikasi di browser:

   APLIKASI UTAMA (Kelana — Travel Planner):
     http://localhost:5173

   APLIKASI PEMESANAN (Singgah — Booking):
     http://localhost:5174

CARA STOP SISTEM:
  docker-compose down

============================================================
  CARA 1 — DOCKER (direkomendasikan)
============================================================

Jalankan semua service sekaligus dari root folder:
  docker-compose up -d

Jalankan dengan rebuild (setelah update kode):
  docker-compose up --build -d

Stop semua service:
  docker-compose down

Rebuild satu service saja:
  docker-compose build orchestrator-service --no-cache
  docker-compose up -d

Cek status semua container:
  docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

Swagger docs via Docker:
  http://localhost:8002/docs   (Mock API)
  http://localhost:8000/docs   (Integration Service)
  http://localhost:8001/docs   (Orchestrator Service)
  http://localhost:8080/docs   (API Gateway)

Catatan:
- File .env wajib ada di root folder (sejajar docker-compose.yml)
- Docker Desktop harus jalan sebelum docker-compose up

============================================================
  CARA 2 — MANUAL (untuk development)
============================================================

Install dependencies (sekali saja per service, dari folder masing-masing):
  cd backend/mock-api && pip install -r requirements.txt
  cd backend/integration-service && pip install -r requirements.txt
  cd backend/orchestrator-service && pip install -r requirements.txt
  cd backend/api-gateway && pip install -r requirements.txt

Jalankan satu per satu di terminal berbeda (urutan wajib):

------------------------------------------------------------
STEP 1 — MOCK API (port 8002)
------------------------------------------------------------
cd backend/mock-api
venv\Scripts\activate
uvicorn main:app --port 8002

------------------------------------------------------------
STEP 2 — INTEGRATION SERVICE (port 8000)
------------------------------------------------------------
cd backend/integration-service
venv\Scripts\activate
uvicorn main:app --port 8000

------------------------------------------------------------
STEP 3 — ORCHESTRATOR SERVICE (port 8001)
------------------------------------------------------------
cd backend/orchestrator-service
venv\Scripts\activate
uvicorn main:app --port 8001

------------------------------------------------------------
STEP 4 — API GATEWAY (port 8080)
------------------------------------------------------------
cd backend/api-gateway
venv\Scripts\activate
uvicorn main:app --port 8080

------------------------------------------------------------
STEP 5 — FRONTEND KELANA (port 5173)
------------------------------------------------------------
cd frontend-jalan
npm install   (hanya pertama kali)
npm run dev

------------------------------------------------------------
STEP 6 — FRONTEND SINGGAH (port 5174)
------------------------------------------------------------
cd frontend-pesan
npm install   (hanya pertama kali)
npm run dev

Catatan:
- File .env wajib ada di root folder (sejajar docker-compose.yml)
  isi: GOOGLE_API_KEY=isi_api_key_kamu
- load_dotenv() akan membaca root .env secara otomatis
- Swagger docs: http://127.0.0.1:PORT/docs

============================================================
  GANTI LLM PROVIDER
============================================================

Edit root .env, ubah LLM_PROVIDER dan LLM_MODEL:

  Gemini (default):
    LLM_PROVIDER=gemini
    LLM_MODEL=gemini-2.5-flash (atau sesuai model yang diinginkan)
    GOOGLE_API_KEY=isi_key

  OpenAI:
    LLM_PROVIDER=openai
    LLM_MODEL=gpt-4o (atau sesuai model yang diinginkan)
    OPENAI_API_KEY=isi_key

  Anthropic (Claude):
    LLM_PROVIDER=anthropic
    LLM_MODEL=claude-3-5-sonnet-20241022 (atau sesuai model yang diinginkan)
    ANTHROPIC_API_KEY=isi_key

  DeepSeek:
    LLM_PROVIDER=deepseek
    LLM_MODEL=deepseek-chat (atau sesuai model yang diinginkan)
    DEEPSEEK_API_KEY=isi_key

Setelah ubah .env, rebuild orchestrator:
  docker-compose build orchestrator-service --no-cache
  docker-compose up -d
