# API Contracts

Folder ini berisi dokumentasi kontrak API antara seluruh layanan dalam sistem Multi-Agent AI Travel Planner.

## Isi

- `data-schemas.md` — Definisi lengkap struktur JSON untuk setiap endpoint Mock API

## Referensi Cepat

| Service | Port | Base URL |
|---|---|---|
| Mock API | 8002 | `http://localhost:8002` |
| Integration Service | 8000 | `http://localhost:8000` |
| Orchestrator Service | 8001 | `http://localhost:8001` |
| API Gateway | 8080 | `http://localhost:8080` |

Swagger docs tersedia di `http://localhost:PORT/docs` untuk setiap service.
